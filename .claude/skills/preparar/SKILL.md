# Prep da próxima sessão

Aqui é onde se gasta raciocínio — uma vez — para que cada turno de jogo seja barato. Use o contexto `[RPG]`; leia `campanha/resumo.md` só se o RESUMO veio truncado.

Escreva em `campanha/prep.md` (substitua o conteúdo; máx. ~400 palavras, telegráfico):
1. **Revisar PJs**: o que cada um quer agora (1 linha cada).
2. **Início forte**: cena *in media res*.
3. **Cenas possíveis** (3–4, situações, não roteiro).
4. **10 segredos e pistas** — fatos descobríveis, não presos a um lugar. Mistérios: 3 pistas por conclusão.
5. **Locais fantásticos** (2–3): nome + 3 aspectos sensoriais/táticos.
6. **NPCs** importantes: desejo, tique, voz.
7. **Facções e honra**: o que cada facção faz esta sessão (movimento do relógio, quem ela cortejaria/ameaçaria), qual dilema testa o código de honra de cada PJ.
8. **Ameaças**: o que os relógios fazem se avançarem; inimigos prontos no formato do `/combate`.
9. **Respiros** (1–2 cenas cotidianas para depois da tensão: mercado, refeição, oficina, ritual local) ligados a laços e facções.
10. **Recompensas** ligadas aos desejos dos PJs.

Depois, numa só chamada, registre o que for canon: `lore + <id> "…"` para NPCs/locais novos, `npc <id> att±N`, `relogio …`, `faccao …`, `fio + …`, `rumor 3` (inspire rumores nos segredos), `nome <cultura>` para nomes novos, `provisoes`. Responda ao jogador só "Prep pronta." (sem spoilers).
